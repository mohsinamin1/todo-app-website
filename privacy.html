Privacy Policy

Last updated: August 28, 2026

This Privacy Policy explains how Todo App handles information when users use the application.

Information We Handle

Depending on the features a user chooses to use, Todo App may handle account information, profile information, todos, university class schedules, profile pictures, photos, videos, passwords, links, and related application data.

Authentication

Todo App uses Supabase Authentication for account creation and sign-in. Google Sign-In may also be used when the user chooses the Google authentication option.

Cloud Synchronization

When a user signs in, supported application data may be synchronized with the application's Supabase database so that the user's data can be available on another device.

Local Data

Users who are not signed in can use supported features with data stored locally on their device.

Profile Pictures and Storage

If a user chooses to upload a profile picture, the image may be stored using the application's Supabase Storage service.

Third-Party Services

The application uses third-party services including Supabase and Google authentication. These services may process information according to their own privacy policies and terms.

Data Deletion

Users may request deletion of their account or associated cloud data through the application's available account controls or by contacting the developer.

Contact

For privacy-related questions or requests, please contact the developer through the contact information associated with the application.
