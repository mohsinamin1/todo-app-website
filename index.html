Todo App

Todo App is a personal productivity application designed to help users manage tasks, university class schedules, deadlines, reminders, and private information.

The application also supports account synchronization and features for managing personal photos, videos, passwords, and links.

Features

  • Todo and deadline management
  • University class scheduling
  • Deadline notifications and class alarms
  • Account synchronization
  • Private vault for personal data
  • Profile management
